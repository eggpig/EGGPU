# ICDE commands

The current command entry is `python -B artifact/icde/tools/reproduce.py` from the repository root. Start with `status` and `verify`; [the artifact guide](../artifact/icde/README.md) explains the explicit build, input and qualification commands and the remaining E1–E6 reproduction work.

Legacy scripts in this directory remain historical source. They do not define the current dataset suite, source qualification or paper results.
