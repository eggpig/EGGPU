# Dataset provenance and release boundary

This directory identifies the 13 graphs used in the EGGPU paper. The framework
repository does **not** bundle the graph files. Use `manifest.tsv` to retrieve
the cited source, verify the exact benchmark input, and reproduce the
simple-graph normalization.

## Input semantics

For every system, the benchmark retains all observed vertices, removes
self-loops, and deduplicates directed arcs or undirected endpoint pairs.
`processed_edges` in `manifest.tsv` is therefore the number of simple edges
seen by the algorithms, not necessarily the edge count printed by the source
catalog. An undirected edge is counted once. A directed edge is counted once
per ordered pair.

The two large-scale inputs have additional pinned artifacts:

- **com-Orkut** is the largest connected component published by SNAP. Source
  labels are deterministically remapped to contiguous zero-based labels. Its
  undirected CSR contains 234,370,166 adjacency entries.
- **GAP-twitter** is the SuiteSparse/GAP matrix, not SNAP's different
  `twitter7` variant. All 61,578,415 rows, including 19,926,185 isolated rows,
  are retained. The topology experiments use the directed pattern with
  implicit unit weights; the random integer values stored in the source matrix
  are not used.

The SHA-256 values in `manifest.tsv` were checked against the local inputs used
to prepare the paper results. `UNKNOWN` means that the repository contains no
verifiable value; it must not be replaced by an inferred filename, license, or
checksum.

## Redistribution boundary

This manifest distinguishes source availability from permission to
redistribute a copy:

- The cited SNAP dataset pages provide downloads and citation information, but
  do not state a dataset redistribution license. SNAP's BSD software license is
  not treated as a license for these third-party graph files. Until the authors
  obtain or verify dataset-specific permission, a public artifact should carry
  only the source URLs, checksums, and preparation instructions for those rows.
- SuiteSparse states that matrices in the collection are licensed under
  [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). GAP-twitter may be
  redistributed with attribution, its embedded metadata, and a clear notice of
  every transformation. The original matrix should remain separately
  identifiable from an EGGPU-derived CSR.
- ER-100k was generated by the project, but the reviewed records do not assign
  a dataset license. The authors should assign a license before placing the
  file in a public deposit.

Accordingly, the safe first Zenodo deposit is a **provenance manifest**, not a
mirror of all third-party data. `zenodo.json` is intentionally marked as a
draft until the remaining rights decisions and the final DOI are supplied.

## Pre-deposit checklist

1. Recompute every supplied file's SHA-256 and compare it with `manifest.tsv`.
2. Preserve source metadata and citations alongside any redistributable matrix.
3. Give transformed artifacts new names and describe relabeling, loop removal,
   deduplication, direction, and weight semantics.
4. Resolve every `UNKNOWN` rights field before including the corresponding
   graph bytes.
5. Replace the placeholder DOI and confirm the creator list in `zenodo.json`.
